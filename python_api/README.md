# Проверка входа через pydnevnikruapi

Требуется Python 3.13+.
Из корня проекта:

```powershell
python -m pip install -r python_api/requirements.txt
python python_api/login_test.py
```

Перед запуском заполните LOGIN и PASSWORD в начале login_test.py.
Скрипт использует AsyncDiaryAPI, вызывает set_token(), затем get_info().
Успех подтверждается только после получения профиля из API.
Код выхода: 0 — успех, 1 — ошибка, 2 — не заполнены данные или отсутствует пакет.
Скрипт не выводит пароль/токен и не сохраняет cookies. login_test.py исключён из Git.

Документация библиотеки: https://github.com/kesha1225/DnevnikRuAPI
Успешность входа зависит от аккаунта и текущей поддержки авторизации библиотекой.


## Экспорт примеров API для разработки PWA

Сохраните TOKEN и data (personId, schoolId) в login_test.py, затем из корня проекта:

```powershell
.\python_api\.venv\Scripts\python.exe python_api\export_api.py
```

По умолчанию выгружается период от 14 дней назад до 14 дней вперёд.
Можно указать даты:

```powershell
.\python_api\.venv\Scripts\python.exe python_api\export_api.py --start 2026-11-01 --end 2026-11-20
```

Ответы сохраняются в `python_api/data/<время запуска>/`: оценки, ДЗ, расписания
учебных групп, справочники, профиль, контекст и дети. ID групп определяются из
ответа groups и ДЗ. При необходимости добавьте `--group-id ЧИСЛОВОЙ_ID`.
Время звонков запрашивается отдельно в timetables.

`manifest.json` содержит список запросов, успешных файлов и ошибок. Ошибка одного
метода не останавливает остальные. Каждый запуск создаёт отдельную папку.
Токен и поля с секретами удаляются из JSON; содержимое ответов и тексты исключений
не выводятся в консоль. Файлы всё равно содержат личные учебные данные и исключены из Git.
Скрипт не скачивает вложения и не изменяет данные Дневник.ру.
Код выхода 0 — все запросы успешны, 1 — часть запросов не получена, 2 — ошибка настройки.
